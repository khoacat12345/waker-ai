# waker-ai v1.0.0 — *Ship while you sleep*

> **Agent claims. Waker verifies. The disk decides.**

`waker-ai` is an independent supervisor for AI coding agents. It watches the
disk — not the agent's words — and keeps waking the agent until every task has
on-disk evidence and every gate is green.

---

## What's new in 1.0

### 1. Vague prompts are no longer a dead end

```bash
waker plan --via opencode --model <provider/model> \
  --prompt "làm app quản lý chi tiêu, có login, xuất excel"
```

One planning turn (OpenCode) writes a `tasks.yaml` contract, then the
**deterministic linter** validates it: missing scope, missing verify, duplicate
ids, overlapping scopes and trivial commands all fail closed before any agent
runs. The LLM proposes; the machine disposes.

### 2. Resume after a crash, reboot or closed terminal

```bash
waker run --resume <run_id> --repo .
```

The ledger, session id, cost, verify cache and fingerprints are restored from
disk. A new **generation** gives the run a fresh kick budget, and kick artifacts
become `kick-N-g1` so the previous audit trail is never overwritten.

### 3. `waker detect`

```text
$ waker detect
 95%  pytest -q                (pyproject.toml)
 75%  npm test                 (package.json scripts.test)
 95%  cargo test               (Cargo.toml)
 95%  go test ./...            (go.mod)
```

### 4. Release automation

`.github/workflows/publish.yml` builds sdist + wheel, runs `twine check`, and
publishes to PyPI with **Trusted Publishing (OIDC)** — or an API token via the
`PYPI_API_TOKEN` secret. Publish the GitHub release to trigger it.

### 5. Demo + docs

- Animated demo at the top of the README (`docs/demo.gif`), generated by
  `scripts/make_demo_gif.py`.
- 45-second recording script: `docs/demo-45s.md`.
- Full changelog: `CHANGELOG.md`.

```bash
pip install "waker-ai @ git+https://github.com/khoacat12345/waker-ai.git"
```

```bash
pip install waker-ai
```

```bash
pip install waker_ai-1.0.0-py3-none-any.whl
```

## Quick start

```bash
waker detect
waker plan --prompt "Phase 1: auth, scope: src/auth/**, verify: pytest tests/auth -q"
waker lint --tasks .waker/tasks.yaml

waker run --tasks .waker/tasks.yaml \
  --adapter opencode --model opencode-go/deepseek-v4.1-flash \
  --test "pytest tests/ -q" --max-kicks 5 --max-cost 0.50
```

Background + live board:

```bash
waker start --detach --tasks .waker/tasks.yaml --adapter opencode --model <model>
waker watch
waker dashboard --open
waker stop
```

Chatbox skill:

```bash
waker setup                       # detect CLIs and install the skill
# or: waker install-skill --for opencode --global
```
